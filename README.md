# Electric Vehicle Sales Analysis (India)

📊 A data analysis project exploring electric vehicle sales across Indian states from 2015 to 2024.

## 📁 Project Structure

- `Electric_Vehicle_Sales_Analysis.ipynb` – Main analysis notebook
- `data/Electric Vehicle Sales by State in India.csv` – Dataset used
- `outputs/` – Graphs and final PDF report

## 📌 Key Insights

- 📈 **Top States** by total EV sales
- 🛵 **Breakdown by vehicle type** (2W, 3W, 4W, others)
- 📆 **Monthly trends** in EV sales
- 🗺️ **Heatmap** of sales by state and year
- 📉 **Cumulative growth** over time

## 💡 Bonus Visualizations

- Vehicle category share by state
- Seasonal trends by year
- Animated line chart for cumulative growth

## 🛠️ Tools Used

- Python, Pandas, Matplotlib, Seaborn
- Jupyter Notebook
